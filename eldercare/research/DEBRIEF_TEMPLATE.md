# Debrief Template — Family Caregiver Interview

Fill this out **within an hour** of the conversation. Memory decays fast
and the things you write down later will be the things you already
thought, not the things you actually heard.

Copy this template per interview. One file per person.

## After all 5 conversations — the cross-cut

Once you've done 5 debriefs, look across them and write down:

- **Things 3+ of them brought up unprompted** — these are real load-bearing
  pain. Build features that address these first.
- **Things 1 of them brought up but no one else** — note but don't build.
- **Things you assumed were important that nobody mentioned** — strongly
  reconsider whether to build them.
- **The cluster of "I'd pay for someone to just handle..."** — the literal
  shape of the willingness-to-pay.
- **The substitute set, aggregated** — the real competition.
- **One sentence each interviewee said** that became the strongest argument
  for / against the product. The "no" stories matter more than the "yes"
  stories at this stage.

Once that cross-cut exists, the product brief writes itself — and it will
write itself differently than the one you came in with. That's the whole
point.
